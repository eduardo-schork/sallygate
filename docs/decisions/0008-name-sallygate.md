# ADR-0008: Name the project Sallygate

- **Status:** Accepted
- **Date:** 2026-11-02

## Context

Working names were Bastion (clashes with Azure Bastion and the generic "bastion host" term) and Sallyport (an existing GitHub project in the vault space, crate and npm name taken).

## Decision

Sallygate: the gate of a sally port, the fortified passage a garrison used to leave and re-enter a fort. On 2026-11-02 the name was free on crates.io, npm, PyPI, Homebrew and GitHub, and `sallygate.com/.app/.dev/.io/.net/.org` were unregistered. Trademarks were not checked.

## Consequences

- To do: register `sallygate.com` (and `.app`), reserve the `sallygate` crate.
